TCP сервер принимает команду на подписку STREAM адрес набор котировок
Если с командой все хорошо, то для этого подписчика создается отдельный UDP сокет, который спамит генерируемыми котировками.

На каждую подписку создается свой UDP сокет со своим потоком.
в UDP канале между подписчиком и сервером должна быть реализация heartbeat
Сервер останавливает котировки через тайм-аут при отсутствии PING

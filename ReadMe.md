# Stock Stalker

TCP/UDP сервер для потоковой передачи котировок с поддержкой heartbeat-механизма.

## Описание

Проект реализует сервер для рассылки котировок акций по подписке. Сервер принимает команды через TCP-соединение, а отправка котировок происходит по UDP.

### Архитектура

- **TCP сервер** (порт по умолчанию) - принимает команды подписки и управления
- **UDP сокеты** - для каждой подписки создается отдельный UDP сокет
- **Heartbeat** - механизм PING/PONG для контроля активности подписчика

### Протокол

#### Команды через TCP

- `STREAM <udp_address> <tickers>` - подписаться на котировки
  - `udp_address` - адрес UDP сокета в формате `host:port`
  - `tickers` - список тикеров через запятую с пробелом (например: `SBER, GAZP, LKOH`)

- `STOP <udp_address>` - остановить поток котировок для указанного адреса

#### Heartbeat

- Клиент должен отправлять `PING` команды через интервал `PING_INTERVAL_SECONDS` (по умолчанию 2 секунды)
- Если в течение `PING_TIMEOUT_SECONDS` (по умолчанию 5 секунд) не поступило PING, сервер останавливает отправку котировок

#### Формат котировки (UDP)

```
<TICKER>|<PRICE>|<VOLUME>|<TIMESTAMP>
```

Пример:
```
SBER|350.50|1000|1689678900
```

## Сборка

```bash
cargo build --release
```

## Запуск сервера

```bash
# С использованием списка тикеров в командной строке
cargo run --bin quote_streamer -- --address 127.0.0.1 --port 8080 --tickers SBER GAZP LKOH
```

## Запуск клиента

```bash
cargo run --bin subscriber -- --tcp-server 127.0.0.1:8080 --udp-address 127.0.0.1:9000 --tickers "SBER, GAZP, LKOH"
```

## Доступные команды в клиенте

- `ping` - проверить состояние соединения
- `stop` - остановить поток котировок
- `exit` - выйти из клиента

## Структура проекта

```
src/
├── lib.rs       # Основная библиотека с константами
├── quote.rs     # Структуры для котировок и стриминга
├── protocol.rs  # Обработка команд протокола
├── tickers.rs   # Управление списком тикеров
└── error.rs     # Определение ошибок

bins/
├── quote_streamer/  # TCP/UDP сервер
└── subscriber/      # Клиент для получения котировок
```

## Конфигурация

- `PING_INTERVAL_SECONDS` (по умолчанию: 2) - интервал между PING командами
- `PING_TIMEOUT_SECONDS` (по умолчанию: 5) - таймаут без активности перед остановкой
- `GEN_QUOTE_RANGE_MIN` (по умолчанию: 100) - минимальное значение для генерации
- `GEN_QUOTE_RANGE_MAX` (по умолчанию: 500) - максимальное значение для генерации
